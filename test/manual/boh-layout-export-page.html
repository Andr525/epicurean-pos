Export your BOH floor plan

Downloads your exact BOH dining-room layout as one file, for the iPhone POS test kit. Read-only: nothing in BOH is changed.

Step 1 — install the button (one time)
  1. Show the bookmarks bar: Firefox: menu View → Toolbars → Bookmarks Toolbar → Always Show. Safari: menu View → Show Favorites Bar.
  2. Drag this gold button onto the bookmarks bar (don't click it here):

    📐 Export BOH layout

    Firefox alternative: right-click the button → Bookmark Link… → Folder Bookmarks Toolbar → Save.
Step 2 — export
  1. Open your Epicurean BOH as usual, in the same browser, and check your dining room looks right. Don't leave an edit half-done.
  2. Click 📐 Export BOH layout on the bookmarks bar.
  3. A message shows the number of rooms, tables, booths, walls and waiter stations, and a file like boh-layout-2026-10-19-1930.json is saved in Downloads.
What the button does — and doesn't do
  • It only reads the floor plan BOH is showing: rooms, every table, booth, wall and object with its number, shape, position, size and seats, and the waiter stations with their tables.
  • It leaves out employee PINs/passwords and guest details (guest names, VIP flags, notes, reservations).
  • It does not save anything in BOH, does not change or clear the browser's storage, does not contact Firebase or any server. The only thing it creates is the downloaded file.
Step 3 — use it in the test kit
  1. Mac: move the downloaded file into the harbor-lane-test-pos folder. When you start Start iPhone POS Test.command, the iPhone and the Mac can load it from there: open the POS, tap the gold TEST tab → Use BOH layout from the Mac.
  2. Or, in any browser running the kit: TEST tab → Import BOH Layout (choose file).
  3. Check the numbers shown, then tap Apply this floor plan.
